# Security Policy

## Supported versions

This repo is a portfolio project and is intended for demonstration and learning use.

## Reporting a vulnerability

If you discover a security issue in this project, please report it privately by opening a security advisory or contacting the maintainer through the repository's security reporting mechanism.

Please avoid disclosing details in public issues.

## Security focus

The project is designed to demonstrate governance, risk, and compliance workflows. It is not intended for production security operations without review.
