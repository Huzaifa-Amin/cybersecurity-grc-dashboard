# Contributing

Thank you for your interest in improving this project.

## Local setup

1. Create a virtual environment:
   python -m venv .venv
2. Activate it:
   .venv\Scripts\activate
3. Install dependencies:
   python -m pip install -r requirements.txt
4. Run the app locally:
   streamlit run app.py
5. Run tests:
   pytest

## Commit conventions

Use clear, conventional commit messages such as:

- feat: add control mapping dashboard
- fix: correct risk scoring formula
- docs: add architecture diagram
- test: add coverage for framework calculations

## Pull requests

Please keep pull requests focused and explain the business/security value of the change.
